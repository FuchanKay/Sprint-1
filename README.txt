Program Controls:
T/Y are used to switch between game objects such as bombs, rocks, vines, walls etc.
E is used to trigger "Snap" behavior which is unique behavior that some objects have when a snap occurs in game.
Space is used to trigger the destruction of any destructable object in the game (Rocks and stone blocks)
R resets the game to the main menu scene 
Q exits the game    

Known bugs:
Game play music continues to play after a reset is triggered
